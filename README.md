# 🏃 Marathon Runner Game

A browser-based marathon running web game inspired by Subway Surfers — but on a straight track!

## 🎮 Play Now

> **[▶ Play on Vercel](https://marathon-runner-game.vercel.app)**

## Features

- 🏁 **4 Race Distances**: 5km · 10km · 21km · 42km
- 🤖 **7 AI Competitors** with unique names and racing strategies
- 🎒 **11 Items**: Speed boosts, weapons, and support items
  - ⚡ Nitro Boost · 🧊 Ice Trap · 🌪️ Tailwind
  - 💧 Water Splash · 🍌 Banana Peel · 📌 Spike Strip · 🥊 Punch
  - 🛡️ Shield · 💰 Coin Magnet · ✨ Revive Star · 💊 Energy Gel
- 🛒 **Shop**: Buy skins, item packs, and upgrade your runner stats
- 💾 **Persistent Progress**: Coins and upgrades saved via localStorage

## Controls

| Key | Action |
|-----|--------|
| `W` / `↑` | Move Up |
| `S` / `↓` | Move Down |
| `A` / `←` | Slow down |
| `D` / `→` | Speed up |
| `Space` / `1` | Use Item Slot 1 |
| `E` / `2` | Use Item Slot 2 |

📱 **Mobile**: Swipe up/down/left/right or use on-screen D-pad buttons

## Tech Stack

- Pure HTML5 Canvas + Vanilla JavaScript
- Web Audio API (synthesized sound effects)
- LocalStorage for game saves
- Zero dependencies

## Play Locally

Just open `index.html` in your browser — no server needed!
